# Leer, y ya.

Un visor pequeño para abrir tus archivos **Markdown** sin cargar un editor.

Este documento permite comprobar cómo se ven los elementos habituales. Abre otro archivo con **Ctrl+O**, con **⌘O** en macOS o arrastrándolo a la ventana.

## Lo que puedes leer

- Párrafos con **negrita**, *cursiva* y ~~texto tachado~~.
- Listas, citas y tablas.
- Bloques de código e imágenes.

> La ventana está dedicada al documento. Todo es de solo lectura.
