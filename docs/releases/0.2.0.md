# Markdown Viewer v0.2.0

## Cambios

- Abre varios documentos en pestañas, conserva su posición de lectura y cambia entre ellos con el teclado. La barra aparece al abrir más de un documento.
- Interfaz más compacta y prioridad de renderizado para la pestaña activa.
- Linux se distribuye como un único tarball x86_64, compilado en Ubuntu 22.04 y validado también en Arch Linux. Sustituye al `.deb` y al tarball exclusivo de Arch.

## Descargas

- Linux x86_64: `markdown-viewer-0.2.0-linux-x86_64.tar.gz`. Extrae el archivo y ejecuta `./markdown-viewer`; incluye instrucciones de instalación e integración con el escritorio.
- Windows x86_64: instalador `.exe`.
- macOS Apple Silicon (arm64): imagen `.dmg`.
- `SHA256SUMS`: sumas de comprobación de los tres paquetes.

## Requisitos y límites

En Linux necesitas glibc 2.35 o posterior, GTK 3 y WebKitGTK 4.1 del sistema. El README incluido detalla las dependencias para Ubuntu/Debian y Arch. El tarball no incluye esas bibliotecas y no admite sistemas con musl como Alpine. No se publican paquetes para Linux ARM ni Mac Intel.

Los instaladores no tienen firma de distribución ni notarización. La aplicación no incorpora actualizaciones automáticas. El cambio de formato en Linux requiere sustituir la instalación anterior siguiendo las instrucciones del tarball; si usabas el `.deb`, desinstálalo antes para evitar entradas de escritorio duplicadas.
