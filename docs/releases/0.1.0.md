Primera versión pública de Markdown Viewer, un visor de Markdown de solo lectura para Windows, macOS y Linux.

## Funciones

- Apertura desde el selector, arrastrando un archivo o pasando su ruta al ejecutable. Las aperturas posteriores usan la ventana existente.
- Tablas, listas de tareas, citas, notas al pie e imágenes locales y remotas HTTPS.
- Diagramas Mermaid, fórmulas LaTeX con KaTeX y resaltado de código con Highlight.js.
- Tema claro y oscuro según el sistema y asociación con archivos Markdown.
- Bibliotecas incluidas localmente y cargadas bajo demanda para priorizar la apertura del texto.

## Descargas

- Windows: instalador `.exe` (x86_64).
- macOS: imagen `.dmg` (Apple Silicon, arm64).
- Ubuntu/Debian: paquete `.deb` (x86_64), con GTK y WebKitGTK del sistema.
- Arch Linux: `markdown-viewer-0.1.0-arch-x86_64.tar.gz`, con instrucciones de instalación dentro del archivo. Requiere un Arch actualizado con sus bibliotecas GTK y WebKitGTK.
- `SHA256SUMS`: sumas SHA-256 de los cuatro paquetes para verificar las descargas.

## Límites conocidos

Los paquetes no tienen firma de distribución ni notarización; Windows y macOS pueden mostrar advertencias de seguridad. Esta versión no incluye actualización automática: descarga e instala la siguiente release para actualizar.

Se admiten archivos UTF-8 de hasta 16 MiB. Las imágenes locales deben estar dentro de la carpeta del documento o sus subcarpetas, con límites de 8 MiB por imagen y 32 MiB por documento. No incluye edición, pestañas ni búsqueda. Los enlaces a otros archivos locales aún no se abren.
